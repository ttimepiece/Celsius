# Celsius
<div align="center">
  A lightweight information panel that lives within your terminal
  
  
  ![Python](https://img.shields.io/badge/python-%233670A0.svg?style=for-the-badge&logo=python&logoColor=ffdd54)
  ![Linux](https://img.shields.io/badge/Linux-%23FCC624.svg?style=for-the-badge&logo=linux&logoColor=black)
</div>


Installation:

Universal with pipx:
`
pipx install celsius
`
Usage:
`
Celsius # Open the overview
Celsius --bar #
`

Themes:
Within the file at: `$HOME/.config/celsius.conf`
All existing themes can be found.

Picking a new theme is as easy as changing the line:
`current_theme = 'claw'`
